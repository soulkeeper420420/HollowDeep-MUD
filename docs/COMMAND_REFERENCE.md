# Registered command reference

This lists all 315 unique registered command names and aliases in the help/staff release. Names sharing a handler are grouped. It describes published source, not proof of live installation. The game indexes the actual table dynamically; duplicate registrations are displayed once.

Use `help commands [page]`, `help search <text> [page]`, `help social [page]`, and `help <command>`. `help spells` retains the full magic catalog; `help spell` describes learned-spell listing. `help search` alone describes room searching.

The ordinary index includes class-specific and staff-role commands for reference. Each action still enforces its own requirements. Original `*` commands appear only for eligible native caretaker/DM classes. Role-only Owners do not receive those native classes. `dmcommands` shows assigned role/builder powers; `dmcommands native [page]` lists eligible original class powers. Target restrictions still apply.

`skills` lists class/level-eligible native abilities; `skills all` lists all 18 catalogued abilities. Readiness also depends on equipment, targets, cooldowns and conditions. This does not add trainable skill points.
