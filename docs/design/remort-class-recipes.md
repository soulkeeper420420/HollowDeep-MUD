# HollowDeep remort class recipes

Resume this design after the base-class and race expansion. This is a design handoff for future work.

## Progression

- Give every base class multiple distinct special-class paths. A player completes two base-class lives to qualify, such as Fighter and Cleric. A pair can offer multiple special classes, each earned through its own trial. Repeating the same base class can also unlock a mastery path.
- Example progression is Fighter → Cleric → Guardian → Aegis Warden. Fighter + Cleric also offers War Priest. Fighter + Fighter offers Weapon Master.
- Each special class has distinct masteries. A super-challenging capstone quest tied to its playstyle unlocks its unique class, mastery upgrades, and hidden abilities or world interactions. Suggested Guardian masteries include Shieldbearer and Sanctuary. Aegis Warden could upgrade Interpose and awaken an heirloom that opens a sealed sanctuary.
- Proposed recipe rule is that either completion order qualifies for the same special classes. The order affects which remort skills become available to carry into each subsequent life.

## Past lives and rewards

- A Past Lives journal records completed classes and subclasses and earned remort skills. A rebirth lets the player pick a remort skill to carry into the next life. Proposed starting limit is one active inherited skill, swappable at the Tree of Life, with more choices earned from different lives.
- Character-bound memory items can grant modest stats or utility while equipped. Proposed starting limit is one active memory item.
- Award Legacy Points on completed rebirths. Possible purchases include a bound weightless satchel with a fixed capacity, special spells, heirloom upgrades, exploration gifts, and convenience or cosmetic rewards. Earlier playtest suggestions were 3 points earned per rebirth, 3 for the satchel, 5 for a spell, and 6 for an heirloom upgrade. These are tuning proposals.
- Keep class unlocks tied to completed lives and quests. Legacy Points buy rewards independently of class eligibility.

## Example recipes

| Completed lives | Special class | Unique class | Playstyle |
|---|---|---|---|
| Fighter + Cleric | Guardian | Aegis Warden | Intercept hits and ward allies |
| Fighter + Cleric | War Priest | Dawn Marshal | Mark enemies and rally allies |
| Fighter + Fighter | Weapon Master | Blade Paragon | Switch stances, parry, and counter |
| Ranger + Cleric | Grovekeeper | Verdant Oracle | Place protective and healing wards |
| Ranger + Thief | Trailghost | Veilwalker | Scout ahead and guide allies |
| Thief + Cleric | Grave Whisperer | Soul Envoy | Question the dead for clues and hidden routes |

The first proposed remort playtest covers Fighter + Cleric with two distinct special-class options, Fighter + Fighter for same-class mastery, and Guardian's capstone as the first unique-class path.
