# HollowDeep World Builder — Round 55

Multi-room development builder extending the Round 54
native-backed area editor.

## Features

- Native-backed room draft creation
- Add rooms to an existing area
- Reciprocal room connections
- Up to 50 rooms per area
- Room descriptions
- Monster and object placement
- Native candidate ZIP exports
- Validation of room records and preserved entities

## Development server

The isolated development server uses:

127.0.0.1:8784

## Dependencies

This is a development source release, not a standalone
installer. The existing private native serializer, templates,
and earlier builder modules are required.

## Production safety

No automatic deployment to the live MUD.
