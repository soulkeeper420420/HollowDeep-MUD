# HollowDeep Round 57 World Builder

Development release of the visual multi-room World Builder.

Features:
- Room and description editing
- Reciprocal room connections
- Native monster and object catalogs
- Placement selection, editing and removal controls
- Server-side native plan validation
- Validated native area ZIP export

Runs privately on localhost port 8786.

Native templates, engine executables and world assets
are not included in this source release.

Native gameplay testing remains outstanding.

No production deployment.
