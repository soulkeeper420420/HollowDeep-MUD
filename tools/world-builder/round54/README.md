# HollowDeep World Builder — Round 54

Development-only World Builder implementation.

Features:
- Reciprocal exits and room descriptions
- Monster and object placement
- Native room export validation
- HTTP draft, link, export and download workflow

This package excludes the private native serializer executable,
databases, exports, and production configuration.

The implementation depends on existing private Round 53/54
modules and native serializer components. It is not a standalone
deployment package.

No live-world deployment is authorized.
