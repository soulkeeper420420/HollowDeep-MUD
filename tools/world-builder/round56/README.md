# HollowDeep World Builder — Round 56

Visual multi-room area editor.

## Features

- Room selection and editing
- Room descriptions
- Reciprocal exits
- Monster and object catalogs
- Placement counts and respawn intervals
- Native-backed room creation
- Validated native ZIP exports

## Development

Runs on localhost port 8785.

Requires existing private native serializer,
templates and earlier builder modules.

Not a standalone installer.

No automatic production deployment.
