# Necromancer creation

The creation-only selector identifies the Necromancer choice
without adding a legacy numeric class ID.

Random base attributes:
- Strength 8-14
- Dexterity 9-15
- Constitution 10-16
- Intelligence 14-18 (prime)
- Piety 14-18 (prime)

The native race adjustments follow these rolls.
Existing characters and ordinary classes are not rerolled.
Native Mage compatibility is preserved.

No additional Necromancer skill progression or rebirth skill
is introduced.
